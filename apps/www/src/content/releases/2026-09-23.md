## Other Improvements

- Code blocks got some much needed TLC, with much more consistent rendering syntax highlighting
- Image blocks now fallback to displaying alt text (when available) if the image isn’t available or hasn’t loaded yet. This is especially useful while offline!
- Saved items that are marked as read now stay visible until you navigate away from your current view, allowing you to unsave the item if desired (instead of having it vanish immediately to the read section)



## Fixes

- Fixed some initial data fetching edge cases which would sometimes place the “Refresh” button in a perpetual “Retrying” state
